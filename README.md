# Flash Memory Wear-Leveling Simulator & Storage Hub

Student: Abhijit Satapathy  
Registration No: 2341019353

## Project Overview

This capstone project implements a software-based virtual NAND flash storage system on Linux.

The project demonstrates:
- Linux
- Linux Device Drivers
- System Programming
- C/C++
- Computer Architecture
- Virtual Hardware Simulation
- Wear-Leveling Algorithms
- Git and Version Control

## Objective

Te objective is to simulate NAND flash blocks and pages, track erase counts, and distribute write/erase operations across blocks using a wear-leveling algorithm.

## Main Components

- Linux Virtual NAND Device Driver
- Shared Driver/User Interface
- C++ Storage Manager
- Wear-Leveling Engine
- Testing and Statistics
